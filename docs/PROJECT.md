# YM Vinil — проектный документ

Этот файл — единственный источник правды по проекту. Любая работа идёт строго
по нему: сначала сверяемся с документом, потом пишем код. Если решение меняется,
сначала правим документ, потом код. Пункты этапов отмечаются по мере готовности.

---

## 1. Суть

Десктопная оболочка для Яндекс Музыки, в которой музыка слушается как винил.
Плейлисты и альбомы пользователя стоят на полке в виде конвертов. Пластинку
достают из конверта, кладут на проигрыватель, запускают мотор, опускают иглу —
и слушают сторону целиком. Сторона закончилась — пластинку переворачивают.

Цель — не «ещё один плеер», а ритуал: осознанное прослушивание альбома
или подборки от начала до конца.

## 2. Принципы (не нарушаются)

1. **Всё локально.** У проекта нет своего сервера, аналитики и телеметрии.
   Запросы идут только с компьютера пользователя на серверы Яндекса.
2. **Токен не покидает Rust.** Токен лежит в системном хранилище паролей,
   JS его никогда не получает. Rust-команды пускают запросы только на
   `api.music.yandex.net` и адреса хранилища, выданные самим API.
3. **Окно входа без прав.** Внешняя страница Яндекса не получает доступа
   к командам приложения (capabilities только у окна `main`).
4. **Без обхода Плюса.** Воспроизведение работает только с подпиской.
   Проект неофициальный, это честно сказано в README.
5. **Свой дизайн.** Вдохновляемся реальными проигрывателями, но не копируем
   чужие логотипы и названия моделей.
6. **Бесплатно и открыто.** MIT, установщики в GitHub Releases.

## 3. Стиль

### 3.1 Проигрыватель (главный референс)

Классический проигрыватель 70-х, **вид строго сверху**:

| Элемент | Как выглядит |
|---|---|
| Корпус | рамка из ореха: тёплое тёмно-коричневое дерево с текстурой волокон |
| Дека | светлая матово-серебристая панель со скруглёнными углами, лёгкая «шлифовка» |
| Пластинка | большая, чёрная, глянцевая, с бороздками и бликом; слегка выходит за деку |
| Яблоко (лейбл) | тёмно-красная «бумага» с напечатанным названием, исполнителем и стороной |
| Правая панель | вертикальная чёрная матовая панель, на ней узел тонарма |
| Тонарм | прямой серебристый рычаг, сверху противовес и узел шарнира, внизу угловая головка с иглой |
| Рычаг LIFT | маленький серебристый рычажок на панели с подписью LIFT — поднимает и опускает иглу |
| Переключатель скорости | круглая ручка внизу панели с отметками 33 / 45 / 78 |
| Кнопка мотора | небольшая красная клавиша внизу деки, светится, когда мотор крутится |
| Шильдик | в левом нижнем углу деки — металлическая табличка «YM vinil» (свой бренд) |

### 3.2 Комната вокруг

- Тёмный тёплый фон, как полутёмная комната с лампой.
- Палитра: орех `#5a2f1c → #2e1a10`, серебро деки `#d8d8d4`, чёрная панель `#151515`,
  лейбл `#7a1f24`, кремовый текст `#f1e6d6`, акцент (кнопка мотора) `#e0312b`.
- Заголовки — антиква с засечками, интерфейс — системный гротеск.
- Анимации физичные: пружины, разгон и торможение, без мгновенных скачков.

## 4. Механика

### 4.1 Пластинка из музыки

| Источник | Как превращается в пластинку |
|---|---|
| Альбом | порядок треков сохраняется; тома (`volumes`) — отдельные диски |
| Плейлист | порядок треков плейлиста |
| «Мне нравится» | сборник из 40 последних лайков |
| «Моя волна» | бесконечная пластинка: треки ротора набираются на диск (~46 мин), при перевороте последней стороны «прессуется» следующий диск |

**Нарезка на стороны.** Сторона рассчитана примерно на **23 минуты**.
Треки идут по порядку и не разрезаются. Если источник длиннее одной
пластинки (≈ 46 мин), он делится на несколько дисков. Внутри диска треки
делятся на две стороны так, чтобы длительности были максимально равны.
Стороны нумеруются буквами сквозь все диски: A/B, C/D, E/F…

На пластинке видны **паузы между треками** — гладкие кольца на бороздках,
расположенные пропорционально длительности треков.

### 4.2 Управление (как на настоящем проигрывателе)

1. **Конверт → проигрыватель.** Клик по конверту на полке — пластинка
   переезжает на диск, лейбл показывает сторону A.
2. **Кнопка мотора.** Запускает диск с разгоном (~1 с); тонарм сам подводится
   к текущему месту стороны и опускает иглу. Повторное нажатие — звук
   «проседает» вместе с диском, игла поднимается, тонарм уходит на стойку.
   Следующий запуск продолжает с начала текущего трека.
3. **LIFT.** Поднять иглу — пауза (звук плавно стихает, треск пропадает).
   Опустить — продолжить с того же места.
4. **Клик по бороздке.** Игла переносится на начало нужного трека.
5. **Скорость 33 / 45 / 78.** 33 — нормальная скорость. 45 и 78 ускоряют
   и диск, и звук вместе с высотой тона (как на настоящем виниле).
6. **Конец стороны.** Игла доходит до выводной канавки, треск ещё пару секунд,
   тонарм уходит на стойку, мотор останавливается. Появляется кнопка
   «Перевернуть» (или «Следующий диск»). Автопереворота по умолчанию нет.
7. **Кнопки ◀◀ / ▶▶ на деке.** Две хромированные клавиши рядом с клавишей
   мотора. ▶▶ — следующий трек; на последнем треке — следующая сторона
   (с переворотом). ◀◀ — в начало трека, если прошло больше 3 с, иначе
   предыдущий трек (с первого трека — последний трек предыдущей стороны).
8. **Тонарм отражает прогресс.** Положение иглы на пластинке соответствует
   времени внутри стороны: от внешнего края к яблоку.

### 4.3 Звук

- Музыка играет через `<audio>`. Rust скачивает mp3 трека целиком
  (`track_bytes`, только хосты `*.yandex.net`), в браузер он попадает
  как blob — так звук можно пропустить через Web Audio без проблем с CORS.
- **Звук винила** (вкл. по умолчанию, выключается одним переключателем
  в настройках, тогда звук чистый и треск молчит). Сила эффекта 0–100 %:
  - тёплый тон: срез инфранизов, мягкий подъём низа (~200 Гц),
    приглушённый верх (high-shelf ~8 кГц и low-pass 12–16 кГц);
  - лёгкое ламповое насыщение (waveshaper);
  - чуть суженная стереобаза;
  - «плавание» скорости: медленный wow (~0,5 Гц) и быстрый flutter (~6 Гц),
    сотые доли процента скорости.
- **Разгон и торможение**: плавное изменение скорости воспроизведения без
  сохранения высоты тона при старте и остановке.
- **Треск винила**: генератор шума в том же Web Audio-контексте, звучит только
  когда игла опущена; громче в паузах между треками и в выводной канавке.
  Громкость — отдельный ползунок.

### 4.4 Атмосфера (этап 3)

- **Цвет под обложку.** Rust скачивает обложку (только с `avatars.yandex.net`),
  React считает основной насыщенный цвет. Лейбл красится в затемнённый вариант
  этого цвета, винил получает едва заметный оттенок. Без обложки — бордовый `#7a1f24`.
- **Переворот.** Пластинка поворачивается вокруг вертикальной оси (~0,7 с),
  буква стороны на лейбле меняется в середине движения.
- **Обратная сторона конверта.** Под проигрывателем — «задник» конверта:
  кремовая бумага, треклист по сторонам с длительностями. Текущий трек
  подсвечен. Клик по треку текущей стороны — игла на этот трек; по треку
  другой стороны — пластинка переворачивается на ту сторону.
- **Системный плеер.** Media Session: название, исполнитель, обложка
  в системном оверлее Windows; медиаклавиши: play/pause — LIFT (или пуск
  мотора), next/prev — соседний трек на стороне.
- **Настройки** (шестерёнка в шапке, хранятся локально): громкость треска
  0–100 %, автопереворот (выкл. по умолчанию: в конце стороны пластинка сама
  переворачивается и мотор запускается снова).

### 4.5 Моя волна

- На полке первым стоит особый конверт «Моя волна».
- Сессия ротора: `POST rotor/session/new` (seed `user:onyourwave`), дальше
  `POST rotor/session/{id}/tracks` с очередью уже полученных треков.
- Треки набираются, пока не наберётся диск (~46 мин), и делятся на стороны A/B.
  Когда доиграна последняя сторона, «Перевернуть» прессует следующий диск
  (C/D, E/F…). С автопереворотом волна играет бесконечно.
- Фидбэк ротору (лучшие рекомендации): `trackStarted`, `trackFinished`, `skip`
  в `rotor/session/{id}/feedback`. Ошибки фидбэка игнорируются.

### 4.6 Полный экран и интерфейс

- **Полный экран.** Кнопка «На весь экран» в шапке, двойной клик по деревянной
  раме проигрывателя или F11. Окно разворачивается на весь экран, остаётся только
  проигрыватель (вписан по высоте) и тонкая строка с треком; подсказки и строка
  гаснут через 3 с без движения мыши. Выход — Esc, F11 или кнопка.
  Слева — выдвижная панель с треклистом (обратная сторона конверта):
  открывается и сворачивается кнопкой «Треклист» у левого края, состояние
  запоминается. Переход в полный экран и обратно не перезапускает анимацию
  установки пластинки.
- **Полка.** Разделы «Моя волна», «Плейлисты», «Альбомы» — у каждого кнопка
  «Скрыть / Показать». Всю полку можно спрятать кнопкой в шапке — тогда
  проигрыватель встаёт по центру. Состояние запоминается.
- **Ламповость.** Тёплый свет лампы сверху и виньетка; конверты стоят на
  деревянных полках; кнопки — тёплые, с янтарной подсветкой; панель настроек —
  кремовая бумага с латунными акцентами.

## 5. Архитектура

| Слой | Где | Ответственность |
|---|---|---|
| Авторизация | `src-tauri/src/auth.rs` | окно входа, перехват токена, keyring |
| API | `src-tauri/src/ym.rs` | `ym_get`, `ym_post`, `ym_post_json`, `track_url`, `track_bytes`, `cover_bytes` |
| Клиент API | `src/api/ym.ts` | типы, загрузка полки и треков |
| Нарезка | `src/player/press.ts` | треки → диски → стороны (чистые функции) |
| Движок | `src/player/engine.ts` | `<audio>`, очередь стороны, разгон, конец стороны |
| Звук | `src/player/fx.ts` | общий AudioContext, цепочка «звук винила», wow/flutter |
| Треск | `src/player/crackle.ts` | генератор шума на Web Audio |
| Волна | `src/player/wave.ts` | сессия ротора, добор треков, фидбэк |
| Геометрия | `src/player/geometry.ts` | углы тонарма, радиусы треков |
| Состояние | `src/store.ts` | аккаунт, полка, пластинка, состояние проигрывателя |
| Цвет | `src/player/color.ts` | основной цвет обложки (чистые функции + загрузка) |
| Настройки | `src/settings.ts` | громкость треска, автопереворот (localStorage) |
| UI | `src/components/` | вход, полка, проигрыватель, конверт, настройки |

Стек: Tauri 2, React 19, TypeScript, Vite, Zustand, Motion.

## 7. Правила разработки

- Сначала документ, потом код.
- Чистая логика (нарезка, геометрия) — в отдельных модулях с тестами.
- Перед коммитом: `npm run build` и `cargo test` проходят.
- Коммиты на русском, по одному логическому шагу, от имени владельца
  репозитория (474K474), без упоминаний ИИ-ассистента.
- **Тестовые сборки.** Пуш в ветку `release` запускает GitHub Actions: установщики
  для Windows, macOS и Linux появляются в Releases как пре-релиз `vВЕРСИЯ`.
  Перед каждой тестовой сборкой поднимаем версию в `package.json`,
  `src-tauri/Cargo.toml` и `src-tauri/tauri.conf.json`.
- **Локальная копия** у автора: `D:\Projects\YM_vinil` — обновляется `git pull`,
  запуск `npm install` и `npm run tauri dev`.
- Готово = работает, проверено, отмечено в этом файле.
